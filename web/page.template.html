Mechanistic interpretability · a reproduction

A network that memorised first, and learned trigonometry later

A one-layer transformer is shown part of the addition table mod and asked to fill in the rest. It memorises what it was shown almost at once, does nothing useful on the rest for thousands of steps, and then generalises. This page reproduces that and takes the finished network apart, using methods from the published work it names as it goes.

01 · the task

The model is never told the rule

It sees pairs of symbols and an answer. Nothing says these are numbers, that + means addition, or that there is a modulus. Shrunk to mod 5 so it fits on a page, the job is to fill in the question marks from the cells it was shown:

At p = that is cells shown and hidden. Two strategies both score 100% on the visible cells. Memorise — there is ample room for a lookup table — which says nothing at all about the hidden cells. Or find the rule. Gradient descent takes the first road, because memorising pays immediately and a general circuit pays nothing until it is finished.

03 · the instrument

Drag through training and watch the circuit form

Each of the 113 input symbols gets a 128-dimensional embedding. Take the Fourier transform of that embedding across the 113 symbols and you get 56 frequencies. Below is how the embedding's power is distributed across them, at whatever step you choose. Four bars are coloured: the frequencies the finished model ends up using. Watch them climb out of the noise floor while the accuracy readout beside them refuses to move.

04 · the algorithm

Addition as rotation

The trained weights represent each number as a point on a circle, at a handful of frequencies, and add by turning further: 

  a  ->  ( cos(w*a), sin(w*a) )        w = 2*pi*k/p, for a few values of k

  cos(w*(a+b)) = cos(w*a)cos(w*b) - sin(w*a)sin(w*b)     <- attention + MLP
  sin(w*(a+b)) = sin(w*a)cos(w*b) + cos(w*a)sin(w*b)

  logit(c)  proportional to   sum over k of  cos( w_k * (a + b - c) )

The last line peaks when every term has phase zero, at c = a + b. Wraparound is free because the circle is periodic.
