# Follow-up training records

These files are the stored records for the follow-up summarised in the repository
README. They are separate from the reproduction runs in `results/`.

- `gpu/results/`: histories, the split file named by each history, and derived
  result files from the GPU runs. Each history records the configuration, the
  split hash, and train and test loss and accuracy at the logged steps.
- `cpu/results/`: the same kinds of files for the CPU runs, including
  `doshi_faithful/`.
- `gpu/run-logs/` and `cpu/run-logs/`: the text logs of those runs. Absolute
  paths from the machines that ran them have been replaced with `research` or
  `python3`. The commands, seeds, and step output are unchanged.

Model checkpoints are not included. The fixed-budget depth comparison described
in the README has not been trained, so it has no records here. This directory
is not regenerated by `scripts/make_report.py`, and it does not contain the
write-up. A review of that write-up by the author is still pending.
